### 1. Findings

#### Module system and JS style (`extensions/**/*.js`)
- **ESM throughout**: `package.json` declares `"type": "module"`. All source files use `import`/`export`. Node builtins imported with `node:` prefix (`node:fs`, `node:path`, `node:child_process`, `node:os`, `node:module`).
- **Default + named exports**: `extensions/reversa.js` exports a default (pre-invoked factory): `export default createReversaPiExtension()`. Lib modules use named exports exclusively (`export function ...`, `export const ...`).
- **JSDoc typing, not TypeScript**: Extensive `@param`, `@returns`, `@typedef` JSDoc annotations throughout. No `.ts` files exist.
- **Error handling**:
  - Custom error: `WriteOutsideSandboxError extends Error` in `guarded-tools.js`
  - Tools **throw** errors (the Pi agent loop converts them to error tool results). The orchestrator uses an out-of-band `.violations` array to detect sandbox violations that the agent loop swallows.
  - User-facing error messages in Portuguese (`"nenhum modelo está selecionado"`), technical messages mixed.
  - `try/catch` with `instanceof Error` checks; fallback to `String(error)`.
- **Async patterns**: `async/await` throughout. `AbortSignal` support via `signal?.addEventListener("abort", ...)`. Promise-wrapping for `execFile`. Concurrency control via manual worker pool (`withConcurrency`).
- **State management**: File-based JSON state (`.reversa/state.json`). Atomic writes: write to `<target>.<pid>.tmp`, then `renameSync`. TOML config via line-scanner (`readSpecsSection`), not a full TOML parser.
- **Dependency injection**: Test seams via optional `deps` parameter (e.g., `runSubagent` accepts `deps = {}`, `loadSdk()` is lazy-imported and can be overridden).

#### Test patterns (`test/`)
- **Framework**: Node.js native test runner (`import test from 'node:test'`), `node:assert/strict`.
- **Fixtures**: `mkdtempSync` + `rmSync` in `finally` blocks. `withTempDir` helper in orchestrator tests.
- **Harness**: `createHarness(commands, options)` factory builds mock Pi API — registers commands, tools, sent messages, notifications.
- **Structure**: Unit tests for individual functions, integration tests for full pipeline runs with mock `runSubagent`.
- **Isolation verification**: `isolation.test.js` greps extension source for forbidden strings (`pi-subagents`, `.pi/agents`) and checks `package.json` has no `pi.agents` block.
- **Snapshot testing**: String matching via `assert.match()` on generated prompts.
